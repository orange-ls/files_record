# 系统驾驶舱（xc_dashboard）

> 系统全局数据概览和快速导航的驾驶舱页面，整合公告、操作手册、FAQ 等信息。

## 模块概述

xc_dashboard 是系统驾驶舱模块，提供系统首页的全局数据概览和快速导航功能。集成了公告管理、操作手册、常见问题（FAQ）、系统图标配置等功能，并内嵌 BPMN.js 用于流程图展示。

## 核心业务流程

1. 公告管理：发布公告 → 用户阅读 → 标记已读
2. 操作手册：上传/维护操作手册文档
3. FAQ 管理：维护常见问题和解答

## 数据模型

| 模型名 | 说明 |
|--------|------|
| `xc.announcement` | 系统公告 |
| `xc.announcement.user` | 公告用户阅读记录 |
| `xc.manual` | 操作手册 |
| `xc.faq` | 常见问题 |
| `xc.sys.icon` | 系统图标配置 |

## 主要功能模块

- **公告管理**：公告发布、阅读状态跟踪
- **操作手册**：系统操作手册的上传和展示
- **FAQ 管理**：常见问题的维护和展示
- **系统图标**：驾驶舱页面图标配置
- **流程图展示**：基于 BPMN.js 的流程图渲染

无

# 不良率报表（xc_defect_rate）

> 产品质量分析平台，提供多维度不良率统计（1-5年）、供应商质量评估、返修详情追踪和服务成本核算能力。

## 模块概述

xc_defect_rate 是信创系统的辅助业务层模块，专注于产品质量数据的统计分析。模块以物料号为核心维度，统计产品在 1-5 年不同时间跨度内的不良率，支持按产品类别、供应商、网络等多维度分析。

模块通过定时任务从 BI 平台同步销量数据，结合内部返修记录计算不良率。数据计算涉及派工单计数、派件未更换计数、故障件未复现计数等多个指标，为供应商管理和产品质量改进提供数据支撑。

模块依赖 `base`、`mail`，相对独立，不依赖其他自定义业务模块。

## 核心业务流程

1. 数据采集：定时任务从 BI 同步销量数据（每天23:50） → 同步服务成本基础数据 → 计算产品存量（每天23:55）
2. 不良率计算：获取总销量 → 统计各年限返修量 → 计算不良率（返修量/总销量） → 扣除派件未更换和故障未复现数量
3. 供应商评估：按供应商维度汇总不良率 → 对比供应商理论不良率 → 生成不良对比结果
4. 返修详情：记录返修工单详情 → 计算工作日TAT → 按时间段（1-6月/7-18月/19月以上）分类统计
5. 数据导出：Excel 导出不良率报表 → 支持自定义筛选条件

## 主要功能模块

- **不良率统计**：按物料号统计1-5年不良率、按时间段（1-6月/7-18月/19月以上）分类、多维度筛选
- **供应商质量评估**：供应商不良率统计、理论不良率对比、不良趋势分析
- **返修详情管理**：返修工单记录、工作日TAT计算、返修原因分类
- **网络产品分析**：网络不良报表、网络产品返修详情
- **RMA分析**：RMA不良率统计、退货数据分析
- **华为业务**：华为不良维修率统计、华为产品质量分析
- **服务成本**：备件服务成本核算、平均转移价格管理
- **数据导出**：Excel批量导出、自定义报表格式

## 外部集成

|------|----------|------|
| BI 平台 | HTTP API | 同步物料销量数据（定时任务） |
| SN溯源系统 | 数据库查询 | 获取产品存量和返修数据 |

## 系统术语

| 术语 | 说明 |
|------|------|
| 不良率 | 产品在指定时间内的返修量与总销量的比值 |
| TAT | 周转时间（Turn Around Time），从返厂到修复完成的工作日数 |
| RMA | 退货授权（Return Merchandise Authorization） |
| 派工单 | 售后服务的维修工单 |
| 派件未更换 | 派出备件但最终未更换的情况（不计入不良） |
| 故障未复现 | 故障件返回后无法复现故障的情况（不计入不良） |
| 理论不良率 | 供应商承诺的产品不良率基准值 |
| 物料存量 | 当前在网运行的产品数量 |

# BPMN 工作流管理（xc_flowable）

> 基于 Flowable BPM 引擎的工作流管理模块，为所有业务模块提供统一的审批流程能力。

## 模块概述

xc_flowable 是系统的工作流引擎集成层，对接外部 Flowable BPM 服务，提供流程定义管理、流程实例管理、审批任务处理等核心能力。其他业务模块（xc_dboms、xc_borrow、xc_production 等）通过继承 `mixin.bpmn.audit` 抽象模型来获得完整的审批流程支持，包括提交、通过、驳回、回退、转办、加签、挂起、激活、撤回等操作。

## 核心业务流程

1. 流程定义同步：从 Flowable 引擎同步流程定义 → 解析 BPMN XML → 提取节点信息 → 配置审批人
2. 流程发起：业务单据提交 → 校验审批人 → 创建流程实例 → 创建审批任务 → 消息通知
3. 审批处理：审批人收到待办 → 通过/驳回/回退/转办/加签 → 更新任务状态 → 流转到下一节点
4. 流程结束：所有节点审批完成 → 更新流程状态 → 回调业务模块

## 数据模型

| 模型名 | 说明 |
|--------|------|
| `bpmn.process.def` | 流程定义，存储 BPMN XML 和节点配置 |
| `bpmn.process.instance` | 流程实例，关联业务单据和流程定义 |
| `bpmn.task` | 审批任务，记录每个审批节点的处理情况 |
| `bpmn.task.node` | 流程节点定义，包含审批人配置和节点类型 |
| `bpmn.time.report` | 流程时效报表 |
| `mixin.bpmn.audit` | 审批混入抽象模型，业务模块继承此模型获得审批能力 |
| `bp.api.def` | Flowable API 基础定义 |
| `bp.base` | Flowable 连接基础类 |
| `bp.res.config.settings` | Flowable 连接配置（服务地址等） |

## 主要功能模块

- **流程定义管理**：同步 Flowable 流程定义、解析 BPMN XML、提取节点信息、配置审批人
- **流程实例管理**：启动流程、挂起/激活流程、删除流程实例
- **审批任务处理**：通过、驳回、回退、转办、加签（前加签/并加签）、撤回
- **审批人管理**：支持单人审批、或签（多人任一通过）、并签（多人全部通过）
- **消息通知**：审批待办邮件通知、飞书消息通知、OA 消息推送
- **审批混入（mixin）**：提供 `BpmnAuditMixin` 抽象模型，业务模块继承即可获得完整审批能力
- **流程版本路由**：通过 `@flowable_shunt` 装饰器实现按流程定义版本分发方法调用

## 外部集成

| 系统 | 集成方式 | 说明 |
|------|----------|------|
| Flowable BPM | REST API | 流程定义同步、流程实例管理、任务操作 |
| 飞书 | HTTP API | 审批待办消息推送、消息卡片更新 |
| OA 系统 | HTTP API | 审批消息推送 |

## 系统术语

| 术语 | 说明 |
|------|------|
| 流程定义 | BPMN 流程图的定义，包含节点、连线、审批人配置 |
| 流程实例 | 流程定义的一次具体执行，关联到具体业务单据 |
| 或签 | 多个审批人中任意一人通过即可流转到下一节点 |
| 并签 | 多个审批人全部通过才能流转到下一节点 |
| 加签 | 审批过程中临时增加审批人 |
| 转办 | 将当前审批任务转交给其他人处理 |
| 回退 | 将流程退回到上一个审批节点 |
| 挂起 | 暂停流程实例的执行 |

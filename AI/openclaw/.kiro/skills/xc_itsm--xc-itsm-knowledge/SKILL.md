# ITSM IT 服务管理（xc_itsm）

> IT 服务管理模块，涵盖合同管理、系统管理、项目管理、任务管理、采购登记、产品信息及供应商管理。

## 模块概述

xc_itsm 是 IT 服务管理模块，提供 IT 资产和服务的全生命周期管理。包括 IT 合同管理、系统（应用）管理、项目管理、任务管理、采购登记、产品信息管理、供应商管理，以及权限申请、资源申请、策略申请等 IT 服务工单功能。

## 核心业务流程

1. IT 合同管理：合同创建 → 关联系统/项目 → 付款登记
2. 系统管理：IT 系统登记 → 关联合同 → 部署信息维护
3. 项目管理：IT 项目创建 → 任务分配 → 进度跟踪
4. 采购登记：采购需求登记 → 产品选型 → 供应商关联
5. IT 服务工单：权限申请 / 资源申请 / 策略申请 → 审批处理

## 主要功能模块

- **合同管理**：IT 合同 CRUD、关联系统和项目、付款记录
- **系统管理**：IT 系统/应用登记、部署信息、关联合同
- **项目管理**：IT 项目创建、标签分类、任务分配
- **任务管理**：任务创建、状态跟踪
- **采购登记**：采购需求登记、产品选型
- **产品信息**：IT 产品信息维护（品牌、类型、部署方式、运维人员等）
- **供应商管理**：供应商信息和联系人维护
- **IT 服务工单**：权限申请、资源申请（含规格配置）、策略申请（含 IP/端口/协议配置）

## 外部集成

无

## 系统术语

| 术语 | 说明 |
|------|------|
| 权限申请 | 申请 IT 系统的访问权限 |
| 资源申请 | 申请 IT 基础设施资源（服务器、存储等） |
| 策略申请 | 申请网络安全策略（防火墙规则等） |

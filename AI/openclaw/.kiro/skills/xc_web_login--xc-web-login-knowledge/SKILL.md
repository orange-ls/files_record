# 单点登录（xc_web_login）

> 自定义登录模块，提供 SSO 单点登录、飞书登录、Odoo 14 旧系统登录兼容及 API 鉴权能力。

## 模块概述

xc_web_login 是登录扩展模块，在 Odoo 原生登录基础上增加了多种登录方式的支持。包括标准 Web 登录、飞书扫码登录、Odoo 14 旧系统登录兼容，以及 API 接口的 Token 鉴权和文件接口支持。

## 核心业务流程

1. Web 登录：用户名密码登录 → Session 创建
2. 飞书登录：飞书扫码 → OAuth 回调 → 用户匹配 → Session 创建
3. API 鉴权：Token 校验 → 接口访问授权
4. 文件接口：鉴权后的文件上传/下载

## 数据模型

无独立数据模型。

## 主要功能模块

- **Web 登录**：自定义登录页面和登录逻辑
- **飞书登录**：飞书 OAuth 扫码登录集成
- **Odoo 14 兼容登录**：旧系统登录方式兼容
- **API 鉴权**：Token 方式的接口鉴权
- **文件接口**：鉴权后的文件操作 API

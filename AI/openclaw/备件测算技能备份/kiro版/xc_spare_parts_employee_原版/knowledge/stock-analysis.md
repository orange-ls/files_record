## 物料前缀维度全景库存分析
- tags: 物料库存, 前缀筛选, 库存分布, 风险分级, 低库存预警, 在途补充
- 问题：按物料代码前缀（如302、69）分析该类物料的整体库存状况、风险等级分布及补库需求
- 数据来源：
  - 主表：base_material（物料基础信息）、reservoir_area_stock（各库区库存）
  - 辅助表：purchasing_transit（采购在途）、dump_transit（转储在途）、rma_transit（RMA在途）
  - 关联方式：base_material LEFT JOIN 库存聚合子查询 + LEFT JOIN 各在途表
- 计算方式：
  - 总体统计：COUNT 物料数，SUM 库存总量，有/无库存物料数
  - 分组聚合：按 spare_parts_category 分组统计；按 city 分组统计
  - 风险分级：按库存区间分段 COUNT（0件/1-4件/5-9件/10-49件/≥50件）
  - 在途汇总：当前库存 + 采购在途 + 转储在途 + RMA在途
- 过滤条件：
  - 主过滤：material_code LIKE '<前缀>-%'（如 '302-%'）
  - 低库存筛选：total_stock > 0 AND total_stock < 5
- 呈现方式：
  - 汇总数字（物料总数、有/无库存数、库存总量）
  - 分级表格（风险等级 → 物料数）
  - Top N 排名（按大类、按城市）
  - 预警列表（低库存物料明细 + 在途情况）
- 备注：
  - 风险等级定义：🔴 高风险(0件) / 🟠 预警(1-4件) / 🟡 关注(5-9件) / 🟢 正常(10-49件) / ✅ 充足(≥50件)
  - 输出报告需包含：总体概况、库存分布、大类分布、城市分布、高风险预警、在途补充、建议措施
  - 分析完成后可导出详细清单为 Excel

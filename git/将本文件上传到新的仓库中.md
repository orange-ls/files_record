好的，我们从零开始，一步一步把你的本地文件夹上传到一个**全新的 GitHub 仓库**（使用 SSH 方式）。  
如果你的电脑上已经有 `.git` 文件夹（比如之前执行过 `git init`），建议先删除它，让整个过程干净无干扰。

---

## 第一步：在 GitHub 上创建新仓库（空仓库）

1. 登录 GitHub，点击右上角 **+** → **New repository**。  
2. Repository name 填你喜欢的名字（例如 `Obsidian_files`）。  
3. **不要**勾选 “Initialize this repository with a README”、“.gitignore” 或 “license”，保持完全为空。  
4. 点击 “Create repository”。  
5. 页面会显示一个 SSH 地址，类似：  
   `git@github.com:你的用户名/仓库名.git`  
   **复制这个地址**，后续要用。

---

## 第二步：在本地删除旧的 Git 记录（如果你之前已经 init 过）

打开 Git Bash，进入你的项目文件夹：
```bash
cd /d/Workspace/Obsidian_files
```
然后删除现有的 `.git` 目录（彻底重置）：
```bash
rm -rf .git
```

---

## 第三步：初始化本地 Git 仓库

```bash
git init
```

---

## 第四步：添加所有文件到暂存区

```bash
git add .
```
（如果有换行符警告，暂时不用理会，不影响上传）

---

## 第五步：提交第一个版本

```bash
git commit -m "首次提交"
```

---

## 第六步：关联远程仓库（使用 SSH 地址）

将你复制的 SSH 地址添加到本地 remote（请替换成你的实际地址）：
```bash
git remote add origin git@github.com:你的用户名/仓库名.git
```

---

## 第七步：推送到 GitHub

```bash
git push -u origin master
```
- `-u` 会把 `origin/master` 设为本地 `master` 的上游，以后只需 `git push` 即可。  
- 如果 GitHub 的默认分支是 `main`，而本地是 `master`，推送后远程会创建 `master` 分支，你可以在 GitHub 上把默认分支改为 `master`，或者推送时用 `git push -u origin main`（前提是你本地也改成了 `main`）。但通常用 `master` 没问题，GitHub 现在默认 `main`，但允许推送 `master`。

---

## 第八步：验证

刷新 GitHub 仓库页面，你应该能看到所有文件已上传。

## 常见问题及解决

### 1. 推送时报错 `fatal: unable to access 'https://...'`  
**原因**：你的 remote 地址可能是 HTTPS 而不是 SSH，或者网络代理问题。  
- 检查 remote 地址：`git remote -v`，确保是 `git@github.com:...` 开头。  
- 如果是 HTTPS，修改为 SSH：`git remote set-url origin git@github.com:用户名/仓库名.git`。  
- 如果网络需要代理，设置代理（例如 `127.0.0.1:7890`）：  
  ```bash
  git config --global http.proxy http://127.0.0.1:7890
  git config --global https.proxy http://127.0.0.1:7890
  ```
  不需要时取消：  
  ```bash
  git config --global --unset http.proxy
  git config --global --unset https.proxy
  ```

### 2. 提示 `Permission denied (publickey)`  
说明你的 SSH 公钥没有添加到 GitHub。  
- 生成密钥（如果还没有）：`ssh-keygen -t rsa -b 4096 -C "your_email@example.com"`  
- 将公钥（`~/.ssh/id_rsa.pub`）内容复制，到 GitHub Settings → SSH and GPG keys → New SSH Key 添加。  
- 测试连通性：`ssh -T git@github.com`，成功会显示你的用户名。

### 3. 本地分支是 `master`，远程默认是 `main`  
推送后远程会有 `master` 分支，不影响。或者你可以把本地分支重命名为 `main`：  
```bash
git branch -m master main
git push -u origin main
```

# 信创样机借用生产占料系统（xc_borrow）

> 管理样机借用申请、物料占料/释放、OA 借用单对接及物料转储的业务模块。

## 模块概述

xc_borrow 是样机借用管理模块，支持营销类和非营销类两种借用场景。核心流程包括借用申请创建、报价单关联、BOM 物料配置、物料占料/释放、审批流程、OA 借用单同步等。模块与报价系统、WMS、SAP 深度集成，实现物料库存实时查询和占料管理。

## 核心业务流程

1. 借用申请：创建借用单 → 关联报价单 → 生成配置详情（BOM）→ 提交审批
2. 物料占料：审批过程中产品经理配置 BOM → 物料计划岗查看库存 → 执行占料操作
3. 审批流程：多节点审批（产品经理配置 → 物料计划反馈 → 工厂确认 → 调度统筹 → 重新生产）
4. 借用生效：审批通过 → 借用单生效 → OA 系统创建借用单
5. 借用关闭：OA 归还确认 → 释放占料 → 关闭借用单（或超期自动关闭）
6. 物料转储：创建转储单 → 审批流程 → SAP 执行转储

## 数据模型

| 模型名 | 说明 |
|--------|------|
| `xc.borrow.apply` | 借用申请单主表 |
| `borrow.detail` | 借用配置详情（BOM 物料明细） |
| `borrow.detail.log` | 配置详情变更日志 |
| `xc.borrow.config.list` | 借用配置清单（产品级） |
| `xc.borrow.approve.report` | 借用审批报表 |
| `xc.borrow.flowable` | 借用审批流程（多版本：v1/251107/251121） |
| `oa.borrow.detail.report` | OA 借用明细报表 |
| `xc.oa.log` | OA 操作日志 |
| `xc.oa.log.detail` | OA 操作日志明细 |
| `sy.material.bom` | 物料 BOM 表 |
| `material.dump.apply` | 物料转储申请 |
| `material.dump.flowable` | 转储审批流程 |

## 主要功能模块

- **借用申请管理**：借用单创建/编辑、报价单关联校验、多视图（草稿/待办/已办/全部）
- **配置详情管理**：BOM 物料配置、物料转换关系、PC-主板 BOM 展开、自定义物料添加
- **物料占料/释放**：WMS 库存查询、占料操作、释放操作、缺口计算
- **审批流程**：基于 xc_flowable 的多版本审批流程（支持流程版本路由）
- **OA 对接**：OA 借用单创建、归还确认、超期自动关闭
- **借用排产导出**：Excel 导出借用排产计划
- **定时任务**：借用单自动生效、超期提醒邮件、超期自动关闭

## 外部集成

| 系统 | 集成方式 | 说明 |
|------|----------|------|
| 报价系统 | PostgreSQL 直连（BCM 库） | 报价单信息、产品配置、BOM 数据 |
| WMS | HTTP API | QG/MU 库存查询、物料占料数据 |
| SAP | PyRFC | 移动平均价查询、物料转储执行 |
| OA 系统 | HTTP API | 借用单创建、归还确认 |

## 系统术语

| 术语 | 说明 |
|------|------|
| 营销类借用 | 用于投标、客户试用、销售借用等营销目的的借用，最大周期 180 天 |
| 非营销类借用 | 用于内部测试、评测、培训等非营销目的的借用 |
| 占料 | 在 WMS 中预留物料库存，防止被其他订单使用 |
| 释放 | 取消物料占用，归还库存可用额度 |
| 缺口数 | 借用所需数量与可用库存之间的差额 |
| 借转销 | 借用完成后直接转为销售，不再归还 |
| 转储 | 物料在不同库位之间的转移操作 |
| Config NO | 产品配置编号，对应 SAP 中的物料配置 |

# 用户管理（xc_user）

> 扩展 Odoo 原生用户体系，提供部门管理、用户信息扩展、产品线归属等功能。

## 模块概述

xc_user 是用户管理扩展模块，在 Odoo 原生用户体系基础上增加了部门管理、用户信息扩展（ITCode、邮箱、角色等）、部门产品线归属等功能。为其他业务模块提供用户身份和组织架构的基础数据支撑。

## 核心业务流程

1. 用户管理：用户信息维护（ITCode、姓名、邮箱、部门归属）
2. 部门管理：部门树形结构维护、部门产品线关联
3. 权限管理：基于安全组的角色权限控制

## 数据模型

| 模型名 | 说明 |
|--------|------|
| `dc.users` | 用户扩展信息（ITCode、邮箱、角色关联等） |
| `dc.dept` | 部门信息 |
| `dc.dept.product` | 部门产品线关联 |

## 主要功能模块

- **用户管理**：用户列表、用户详情、ITCode 关联
- **部门管理**：部门树形结构（基于 zTree 组件）、部门 CRUD
- **部门产品线**：部门与产品线的关联管理
- **登录页扩展**：自定义登录页面样式

## 外部集成

无

## 系统术语

| 术语 | 说明 |
|------|------|
| ITCode | 员工工号/登录账号，系统中用户的唯一标识 |
| 部门产品线 | 部门负责的产品线归属关系 |

# Minecraft Java版 1.20+ 常用指令大全

> 适用版本：Java版 1.19-1.21通用，核心语法兼容主流生存版本 通用说明：`@s` = 自己；`@p` = 最近玩家；`~ ~ ~` = 当前坐标；需开启作弊模式方可使用

------

## 一、游戏基础设置

### 1. 游戏模式切换

**命令示例**

```
/gamemode survival
```

**参数说明**

| 参数值    | 中文名称 | 说明                                         |
| --------- | -------- | -------------------------------------------- |
| survival  | 生存模式 | 正常生存玩法，需要采集资源、对抗生物         |
| creative  | 创造模式 | 无限物品、飞行，可自由放置破坏方块           |
| spectator | 旁观模式 | 穿透方块飞行，无法交互，用于观察             |
| adventure | 冒险模式 | 无法破坏方块，仅可通过工具交互，适合解谜地图 |

### 2. 时间设置

**命令示例**

```
/time set day
```

**参数说明**

| 参数值/格式 | 说明                               |
| ----------- | ---------------------------------- |
| day         | 设置为白天（对应游戏刻1000）       |
| night       | 设置为夜晚（对应游戏刻13000）      |
| 0           | 日出时刻                           |
| 12000       | 日落时刻                           |
| add 数值    | 增加指定游戏刻（1现实秒=20游戏刻） |

### 3. 天气设置

**命令示例**

```
/weather clear
```

**参数说明**

| 参数值  | 中文名称 | 说明                                     |
| ------- | -------- | ---------------------------------------- |
| clear   | 晴天     | 关闭雨雪天气                             |
| rain    | 雨天     | 开启降雨，寒冷区域对应降雪               |
| thunder | 雷雨天   | 雷雨天气，可触发引雷附魔、闪电苦力怕变身 |

### 4. 难度与出生点

**命令示例**

```
/difficulty normal
/spawnpoint @s
```

**参数说明**

| 命令           | 参数值      | 说明                           |
| -------------- | ----------- | ------------------------------ |
| /difficulty    | peaceful    | 和平难度，无攻击性生物生成     |
| /difficulty    | easy        | 简单难度                       |
| /difficulty    | normal      | 普通难度                       |
| /difficulty    | hard        | 困难难度                       |
| /spawnpoint    | @s / 玩家名 | 设置指定玩家的重生点为当前位置 |
| /setworldspawn | -           | 设置整个世界的公共出生点       |

### 5. 核心游戏规则

**命令示例**

```
/gamerule keepInventory true
```

**参数说明**

| 规则ID          | 可选值     | 说明                                           |
| --------------- | ---------- | ---------------------------------------------- |
| keepInventory   | true/false | 死亡是否保留物品栏（true=不掉落物品）          |
| mobGriefing     | true/false | 生物是否破坏方块（false=苦力怕、末影人不毁图） |
| doDaylightCycle | true/false | 是否开启昼夜循环                               |
| doWeatherCycle  | true/false | 是否开启天气变化                               |

## 三、传送指令

### 1. 基础传送

**命令示例**

```
/tp @s 100 64 200
```

**参数说明**

| 格式                   | 说明                                                         |
| ---------------------- | ------------------------------------------------------------ |
| /tp <目标> <x> <y> <z> | 将目标传送到指定三维坐标                                     |
| /tp <目标A> <目标B>    | 将目标A传送到目标B身边                                       |
| ~ ~ ~                  | 代表当前位置坐标，可搭配相对数值，如`~ ~1 ~` = 当前位置上方1格 |

### 2. 坐骑/宠物专属传送

**命令示例**

```
# 骑马时连带马一起传送（稳妥写法，不会下马）
execute as @e[type=horse,sort=nearest,limit=1] run tp @s 100 64 200

# 找回最近的驯服狼（狗）
tp @e[type=wolf,sort=nearest,limit=1] @s

# 找回最近的驯服猫
tp @e[type=cat,sort=nearest,limit=1] @s
```

**目标选择器参数说明**

| 参数         | 说明                              |
| ------------ | --------------------------------- |
| type=xxx     | 指定生物类型，如horse/wolf/cat    |
| sort=nearest | 按距离由近到远排序                |
| limit=1      | 仅选取最近的1个目标，避免批量传送 |

## 四、物品给予指令

### 1. 基础物品给予

**命令示例**

```
/give @s minecraft:diamond 64
```

**语法格式**：`/give <目标> <物品ID> [数量]` **常用物品ID表**

| 物品ID                | 中文名称 | 推荐数量 | 说明                   |
| --------------------- | -------- | -------- | ---------------------- |
| minecraft:diamond     | 钻石     | 64       | 制作钻石装备与工具     |
| minecraft:blaze_rod   | 烈焰棒   | 16       | 酿造药水、制作末影之眼 |
| minecraft:ender_eye   | 末影之眼 | 12       | 激活末地传送门         |
| minecraft:ender_pearl | 末影珍珠 | 16       | 短距离瞬移道具         |
| minecraft:obsidian    | 黑曜石   | 64       | 建造下界传送门         |
| minecraft:saddle      | 马鞍     | 1        | 骑乘马、猪等生物       |
| minecraft:name_tag    | 命名牌   | 5        | 给驯服生物命名         |

### 2. 进阶：自定义附魔物品（NBT写法）

直接生成自带全套附魔的成品装备，无需逐个附魔 **命令示例（成品掠夺剑）**

```
/give @s minecraft:diamond_sword{Enchantments:[{id:"minecraft:sharpness",lvl:5},{id:"minecraft:looting",lvl:3},{id:"minecraft:unbreaking",lvl:3},{id:"minecraft:mending"}],display:{Name:'{"text":"烈焰人专用剑"}'}} 1
```

**语法说明**：在物品ID后加`{Enchantments:[{id:"附魔ID",lvl:等级},...]}`可写入多个附魔，`display:{Name:...}`可自定义物品名称。

## 五、附魔指令与魔咒对照表

### 1. 基础附魔指令

**命令示例**

```
/enchant @s sharpness 5
```

> 作用：给**手中手持的物品**附加指定附魔，不可超过原版最高等级，冲突附魔无法共存 **语法格式**：`/enchant <目标> <魔咒ID> [等级]`

### 2. 常用魔咒ID对照表

| 魔咒ID             | 中文名称 | 适用物品       | 原版最高等级 | 备注                                           |
| ------------------ | -------- | -------------- | ------------ | ---------------------------------------------- |
| sharpness          | 锋利     | 剑、斧         | V            | 提升所有生物的近战伤害                         |
| smite              | 亡灵杀手 | 剑、斧         | V            | 额外提升亡灵生物伤害（僵尸、骷髅、凋零骷髅等） |
| bane_of_arthropods | 节肢杀手 | 剑、斧         | V            | 额外提升节肢生物伤害（蜘蛛、蠹虫、蜜蜂等）     |
| knockback          | 击退     | 剑             | II           | 攻击时将生物击退更远                           |
| fire_aspect        | 火焰附加 | 剑             | II           | 攻击时点燃目标，可直接获得熟肉                 |
| looting            | 抢夺     | 剑             | III          | 击杀生物时增加掉落物数量，刷烈焰人必备         |
| efficiency         | 效率     | 镐、斧、锹、锄 | V            | 提升挖掘速度                                   |
| silk_touch         | 精准采集 | 工具           | I            | 挖掘方块直接掉落方块本身，与时运互斥           |
| unbreaking         | 耐久     | 工具、装备     | III          | 概率不消耗耐久，延长使用寿命                   |
| mending            | 经验修补 | 工具、装备     | I            | 吸收经验球修复耐久，与无限互斥                 |
| protection         | 保护     | 防具           | IV           | 提升全类型伤害减免                             |
| infinity           | 无限     | 弓             | I            | 射箭不消耗普通箭矢，与经验修补互斥             |
| power              | 力量     | 弓             | V            | 提升弓箭基础伤害                               |

### 3. 附魔互斥规则

- 武器伤害类：锋利 / 亡灵杀手 / 节肢杀手 三者互斥，仅可存在一种
- 工具采集类：时运 / 精准采集 二者互斥
- 弓类：无限 / 经验修补 二者互斥
- 靴子：冰霜行者 / 深海探索者 二者互斥
- 弩：多重射击 / 穿透 二者互斥
- 三叉戟：激流 / 忠诚、引雷 互斥

## 六、状态效果指令

**命令示例**

```
/effect give @s fire_resistance 99999 0 true
```

**语法格式**：`/effect give <目标> <效果ID> [持续时间] [等级] [隐藏粒子]` **常用效果表**

| 效果ID          | 中文名称 | 推荐等级 | 说明                       |
| --------------- | -------- | -------- | -------------------------- |
| speed           | 速度     | 1        | 提升移动速度               |
| fire_resistance | 防火     | 0        | 免疫火焰伤害，下界探险必备 |
| night_vision    | 夜视     | 0        | 黑暗环境清晰视物           |
| strength        | 力量     | 1        | 提升近战伤害               |
| regeneration    | 生命恢复 | 1        | 持续恢复生命值             |

> 参数末尾加`true`可隐藏药水粒子效果，持续时间填`99999`近似永久

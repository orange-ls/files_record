## **Windows激活**

### 1. 开源脚本HWID永久激活（推荐）

这是目前用户反馈最稳定、操作最简便的方式，基于开源的Microsoft Activation Scripts工具实现，可直接获取数字许可证完成永久激活。

1. 右键点击开始菜单，以管理员身份打开PowerShell（注意不是CMD）
2. 在命令行中输入命令 irm https://get.activated.win | iex 后按下回车键
3. 等待脚本加载完成后，输入数字**1**选择HWID模式进行Windows激活，该步骤需要联网校验
4. 等待几分钟后，界面提示激活成功即可完成操作

### 2. 微软官方数字许可证迁移激活

这是唯一完全正规、安全无毒的永久激活方案，适合设备之前正版激活过Win10/Win11、且绑定过微软账号的用户，重装系统后失效时使用。

1. 登录之前激活过该设备的微软账号
2. 依次打开设置 > 系统 > 激活页面
3. 点击【激活疑难解答】选项，选择「我最近更改了此设备上的硬件」
4. 系统会自动匹配云端存储的数字许可证，提示「Windows已使用数字许可证激活」即为成功

### 3. KMS命令行激活（无需第三方工具）

该方式通过系统自带命令实现，无需下载额外工具，有效期为180天，到期后会自动续期，适合临时使用的场景。

1. 右键点击开始菜单，打开Windows终端（管理员模式）
2. 按顺序依次输入三条命令：
   - slmgr -ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
   - slmgr -skms kms.0t.net.cn
   - slmgr -ato
3. 命令执行完成后，即可完成KMS方式的系统激活

### 4. 验证激活状态的方法

按下Win+R快捷键打开运行对话框，输入slmgr.vbs /xpr后点击确定，弹出的Windows Script Host提示框会显示当前激活状态：

- 显示「计算机已永久激活」：代表系统已成功永久激活
- 显示「计算机已激活 + 激活到期时间」：属于KMS批量授权版本
- 提示「Windows处于通知模式 / 找不到产品密钥」：说明系统尚未激活

1、创建虚拟环境
    在终端输入：python -m venv .venv
    
    注：
	1.1、python：默认环境变量中的python版本，如需更改可以替换为具体py版本的.exe路径，
		例：D:\Python\Python3.11\python.exe -m venv .venv
	1.2、-m venv：为固定格式，不能修改
	1.3、.venv：创建虚拟环境的位置和名字。“.”代表当前目录，venv代表虚拟环境的名字

2、进入虚拟环境
    .venv\Scripts\activate

3、下载包
    pip install -r .\requirements.txt  或  pip install -r requirements.txt

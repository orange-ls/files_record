本文档记录了在同一台 Linux 服务器上，使用 Docker Compose 部署 Redis 和 Flowable，以及通过源码方式部署 Odoo 14 的完整过程。所有步骤均在实际操作中验证通过。

## 一、安装 PostgreSQL 数据库

### 1.1 安装 PostgreSQL

更新系统包索引，然后安装 PostgreSQL 及其附加组件：

```bash
sudo apt update
sudo apt install -y postgresql postgresql-contrib
```

安装完成后，PostgreSQL 服务会自动启动。相关目录如下（以版本 14 为例）：

- **数据目录**：`/var/lib/postgresql/14/main`
- **配置文件目录**：`/etc/postgresql/14/main`
- **服务管理命令**：`systemctl`（或 `service postgresql`）

查看服务状态：

```bash
sudo systemctl status postgresql
```

------

### 1.2 配置远程连接（允许外部访问）

PostgreSQL 默认只允许本地连接（`localhost`）。如需从其他机器（如 Navicat）远程访问，需要修改两个配置文件。

#### 1.2.1 修改 `postgresql.conf`（监听所有地址）

```bash
sudo vi /etc/postgresql/14/main/postgresql.conf
```

找到 `listen_addresses` 行，将其修改为：

```text
listen_addresses = '*'
```

如果该行被注释，取消注释并修改。保存退出。

#### 1.2.2 修改 `pg_hba.conf`（认证规则）

```bash
sudo vi /etc/postgresql/14/main/pg_hba.conf
```

在文件末尾添加一行，允许来自任意 IP 的连接使用 MD5 密码认证（请根据安全需求调整 IP 范围）：

```text
host    all             all             0.0.0.0/0               md5
```

如果仅允许特定子网，可将 `0.0.0.0/0` 替换为你的网段（例如 `192.168.1.0/24`）。

------

### 1.3 重启 PostgreSQL 使配置生效

```bash
sudo systemctl restart postgresql
```

------

### 1.4 创建数据库用户（用于 Odoo）

切换到 PostgreSQL 超级用户 `postgres`，然后创建 Odoo 专用用户并赋予超级用户权限（也可按需赋予更精确的权限）。

```bash
# 切换到 postgres 系统用户
sudo su - postgres

# 进入 psql 命令行
psql

# 在 psql 中执行：
CREATE USER odoo WITH PASSWORD 'odoo123' SUPERUSER;
# 如需创建数据库，也可一并创建：
CREATE DATABASE ts_bcm OWNER odoo;

# 查看用户列表
\du

# 退出 psql
\q

# 退出 postgres 用户
exit
```

------

### 1.5 使用 Navicat 远程连接

1. 确保服务器防火墙放行 PostgreSQL 端口（默认 5432）：

   ```bash
   sudo ufw allow 5432/tcp
   ```

   如果使用云服务商，还需在安全组规则中开放端口。

2. 在 Navicat 中新建 PostgreSQL 连接，填写：

   - **主机**：服务器公网 IP
   - **端口**：5432
   - **用户名**：odoo
   - **密码**：odoo123
   - **数据库**：ts_bcm（或任意已存在的数据库）

3. 点击“测试连接”，若提示成功则配置完成。



## 二、Docker Compose 部署 Redis

### 2.1 准备工作
创建项目目录：
```bash
mkdir -p ~/redis-stack/{data,conf}
cd ~/redis-stack
```

### 2.2 创建 Redis 配置文件 `conf/redis.conf`

```properties
bind 0.0.0.0
protected-mode yes
port 6379
requirepass YOUR_STRONG_PASSWORD    # 请修改为强密码

save 900 1
save 300 10
save 60 10000

dir /data
dbfilename dump.rdb

appendonly yes
appendfilename "appendonly.aof"
```



### 2.3 创建 `docker-compose.yml`

```yaml
version: '3.8'

services:
  redis:
    image: redis:7.2
    container_name: redis
    command: ["redis-server", "/usr/local/etc/redis/redis.conf", "--requirepass", "${REDIS_PASSWORD}"]
    ports:
      - "6379:6379"
    volumes:
      - "./data:/data"
      - "./conf/redis.conf:/usr/local/etc/redis/redis.conf:ro"
    environment:
      - REDIS_PASSWORD=${REDIS_PASSWORD}
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "redis-cli", "-a", "${REDIS_PASSWORD}", "PING"]
      interval: 10s
      timeout: 3s
      retries: 5
      start_period: 5s
```

### 2.4 创建环境变量文件 `.env`

```bash
REDIS_PASSWORD=YOUR_STRONG_PASSWORD
REDIS_PORT=6379
```

### 2.5 启动与验证

```bash
docker-compose up -d
docker-compose ps
docker exec -it redis redis-cli -a YOUR_STRONG_PASSWORD ping   # 应返回 PONG
```

## 三、Docker Compose 部署 Flowable（连接已有 PostgreSQL）

> **前提**：已有可用的 PostgreSQL 实例（本文假设运行在宿主机，IP 为 `172.17.0.1`，数据库名 `flowable`，用户 `flowable`，密码 `flowable`）。

### 3.1 创建项目目录

```bash
mkdir -p /opt/flowable
cd /opt/flowable
```

### 3.2 创建 `docker-compose.yml`

```yaml
version: '3.8'

services:
  flowable:
    image: flowable/flowable-ui
    container_name: flowable-app
    ports:
      - "8080:8080"
    environment:
      - SPRING_DATASOURCE_DRIVER-CLASS-NAME=org.postgresql.Driver
      - SPRING_DATASOURCE_URL=jdbc:postgresql://172.17.0.1:5432/flowable   # 修改为实际IP和端口
      - SPRING_DATASOURCE_USERNAME=flowable
      - SPRING_DATASOURCE_PASSWORD=flowable
    restart: unless-stopped
```

### 3.3 启动并验证

```bash
docker-compose up -d
docker-compose logs -f   # 查看日志，确认无连接错误
```

访问 `http://服务器IP:8080/flowable-ui`，默认管理员账号 `admin` / `test`。

### 3.4 修改管理员密码（推荐通过界面）

登录后进入 **IDM** 应用 → 右上角用户头像 → Edit Profile → 修改密码。

如需在首次启动时预设密码，可在 `environment` 中添加：

```yaml
- FLOWABLE_IDM_USER=admin
- FLOWABLE_IDM_PASS=新密码
```



## 四、编译安装 Python 3.8.8（源码方式）

Odoo 14 对 Python 版本有严格兼容性要求，官方推荐使用 Python 3.8 系列。这里以 **Python 3.8.8** 为例。

---

### 4.1 下载 Python 源码

可以从官方源下载，或通过 `wget` 直接在服务器获取：

```bash
cd /opt
wget https://www.python.org/ftp/python/3.8.8/Python-3.8.8.tar.xz
```

> **备用下载**：如果网络较慢，可在本地下载后通过 `rz` 上传（需先安装 `lrzsz`）：
>
> ```bash
> sudo apt install -y lrzsz
> rz
> ```

------

### 4.2 解压源码

```
tar -xvf Python-3.8.8.tar.xz
cd Python-3.8.8
```

------

### 4.3 安装编译依赖

编译 Python 需要 `gcc` 编译器及相关开发库。执行以下命令安装：

```bash
sudo apt update
sudo apt install -y gcc make build-essential libssl-dev zlib1g-dev \
    libbz2-dev libreadline-dev libsqlite3-dev wget curl llvm \
    libncurses5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev libffi-dev liblzma-dev
```

------

### 4.4 配置编译选项（关键步骤）

> **⚠️ 重要**：必须加入 `--with-ssl` 参数，否则编译出的 Python 将缺少 `ssl` 模块，导致 Odoo 无法正常使用。

```bash
mkdir /usr/local/python3.8.8
查看是否安装
gcc --version
没有安装请安装gcc
updateupd install gcc

./configure --prefix=/usr/local/python3.8.8 --enable-optimizations --with-openssl=/usr
```

- `--prefix`：指定安装目录，便于后续管理
- `--enable-optimizations`：启用性能优化（推荐）
- `--with-ssl`：强制启用 SSL 支持

------

### 4.5 编译与安装

```bash
make -j $(nproc)   # 使用所有 CPU 核心加速编译
sudo make install
```

------

### 4.6 处理常见报错

#### 报错：`python: can't decompress data; zlib not available`

**原因**：缺少 `zlib` 开发库，或 Python 未正确识别。

**解决方法**：

1. 安装 `zlib` 相关包：

   ```bash
   sudo apt install -y zlib1g-dev
   ```

2. 编辑 `Modules/Setup` 文件，取消 `zlib` 相关注释：

   ```bash
   vi Modules/Setup
   ```

   找到以下行并**去掉注释**（删除行首的 `#`）：

   ```text
   zlib zlibmodule.c -I$(prefix)/include -L$(exec_prefix)/lib -lz
   ```

   保存退出。

3. 重新执行配置和编译：

   ```bash
   make clean
   ./configure --prefix=/usr/local/python3.8.8 --enable-optimizations --with-ssl
   make -j $(nproc)
   sudo make install
   ```

------

### 4.7 验证安装

检查 Python 版本及 SSL 模块是否正常：

```bash
/usr/local/python3.8.8/bin/python3 --version
/usr/local/python3.8.8/bin/python3 -c "import ssl; print(ssl.OPENSSL_VERSION)"
```

如果能正常输出版本号，说明 Python 安装成功且 SSL 模块可用。

## 五、源码部署 Odoo 14

### 5.1 环境准备（务必解决 Python SSL 问题）

Odoo 14 需要 Python 3.8/3.9 且必须支持 `ssl` 模块。如果使用源码编译的 Python，需要重新编译加入 SSL 支持。

#### 5.1.1 安装 OpenSSL 开发包

```bash
sudo apt-get update
sudo apt-get install -y libssl-dev
```

### 5.2 创建 Odoo 用户（可选，但推荐）

```bash
sudo adduser --system --group odoo
sudo mkdir -p /opt/odoo14
sudo chown -R odoo:odoo /opt/odoo14
```

### 5.3 克隆 Odoo 源码及创建虚拟环境

源码放在 `/opt/odoo14/ts-bcm`，并创建虚拟环境于 `/opt/odoo14/odoo-14-venv`。

```bash
cd /opt/odoo14
git clone -b 14.0 https://github.com/odoo/odoo.git ts-bcm   # 或复制已有源码
/usr/local/bin/python3 -m venv odoo-14-venv
source odoo-14-venv/bin/activate
```

### 5.4 安装依赖包

首先升级 pip 和 setuptools：

```bash
pip install --upgrade pip setuptools wheel：
```

```bash
cd /opt/odoo14/ts-bcm
pip install -r requirements.txt
```

> **特别注意**：若遇到 `num2words` 安装失败，可尝试手动安装或更换镜像源（如清华 HTTP 镜像）。

### 5.5 配置 Odoo 配置文件

创建 `/opt/odoo14/ts-bcm/odoo.conf`：

```ini
[options]
addons_path = /opt/odoo14/ts-bcm/addons
data_dir = /opt/odoo14/ts-bcm/data
db_host = 127.0.0.1
db_port = 5432
db_user = odoo_user     # 替换为实际 PostgreSQL 用户
db_password = odoo_pass
db_name = ts_bcm
logfile = /opt/odoo14/ts-bcm/log/odoo.log
log_level = info
```

创建日志目录：

```
mkdir -p /opt/odoo14/ts-bcm/log
```

### 5.6 初始化数据库

**删除旧数据库（若存在）并重建**：

```
sudo -u postgres dropdb --if-exists ts_bcm
sudo -u postgres createdb -O odoo_user ts_bcm
```

**执行初始化**（强制安装 base 模块）：

```
cd /opt/odoo14/ts-bcm
source /opt/odoo14/odoo-14-venv/bin/activate
python3 odoo-bin -c odoo.conf -d ts_bcm -i base --stop-after-init
```

查看日志确认无错误：

```
tail -50 log/odoo.log | grep -i error
```

### 5.7 启动 Odoo 服务（后台运行）

#### 使用 systemd（推荐生产环境）

创建 `/etc/systemd/system/ts-bcm.service`：

```ini
[Unit]
Description=ts-bcm
Requires=postgresql.service
After=network.target postgresql.service
[Service]
Type=simple
SyslogIdentifier=ts-bcm
PermissionsStartOnly=true
ExecStart=/opt/odoo14/odoo-14-venv/bin/python3 /opt/odoo14/ts-bcm/odoo-bin -c /opt/odoo14/ts-bcm/odoo.conf
StandardOutput=journal+console
[Install]
WantedBy=multi-user.target
```

启用并启动：

```
sudo systemctl daemon-reload
sudo systemctl enable ts-bcm
sudo systemctl start ts-bcm
```

### 5.8 访问Odoo

打开浏览器访问 `http://服务器IP:8069`，默认管理员账号 `admin`，密码 `admin`

## 六、常见问题与解决方法

| 问题现象                             | 可能原因                              | 解决方案                                                  |
| :----------------------------------- | :------------------------------------ | :-------------------------------------------------------- |
| Odoo 启动报 `KeyError: 'ir.http'`    | 数据库未初始化                        | 执行 `-i base --stop-after-init`                          |
| Odoo 日志报 `No module named '_ssl'` | Python 编译缺少 SSL 支持              | 重装 OpenSSL 开发包并重新编译 Python                      |
| `pip install` 报 SSL 错误            | pip 使用 HTTPS 源但 ssl 模块不可用    | 使用 HTTP 源并添加 `--trusted-host`                       |
| `num2words` 找不到版本               | 镜像源未同步该包                      | 换用清华 HTTP 源或手动下载 wheel                          |
| Flowable 连接 PostgreSQL 失败        | IP 地址不正确（容器内无法访问宿主机） | 使用 `172.17.0.1`（Docker 网桥）或 `host.docker.internal` |

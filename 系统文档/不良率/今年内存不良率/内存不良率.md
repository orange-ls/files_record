在“在保不良率-逐年在保不良率”后增加“今年内存不良率”模型

参考代码：.\xc_addons\xc_defect_rate\models\warranty_defect_rate.py



##### 模型：

**今年内存不良率：**

1、页面按钮等：

​	1.1、"内存类型"下拉框：'DDR4内存', 'DDR5内存'。默认值为'DDR4内存'

​	1.2、“维度”下拉框：物料号、捆绑料号、。默认值是"物料号"

​	1.3、刷新按钮

​	1.4、导出按钮

2、字段：

​	维度、销售月份、在保月份、销量、在保数量、报修数量、在保月故障率

​	

3、刷新按钮调用刷新方法，更新中间表。选择下拉框的值后，进行数据获取。不需要设置任何权限。

4、刷新逻辑：

​	4.1、报修数量：

```sql
-- 计算维修收发货表-报修数量
SELECT
	gzjwlh,
	TO_CHAR(field_131ea__c, 'YYYY-MM') AS sales_month,
	bm.spare_parts_category AS big_category,
	count(*) AS repair_num
FROM compute_product_report cpr
	LEFT JOIN base_material bm ON bm.material_code = cpr.gzjwlh
WHERE
	EXTRACT(YEAR FROM field_131ea__c) = EXTRACT(YEAR FROM CURRENT_DATE)
	AND bm.spare_parts_category IN ('DDR4内存', 'DDR5内存')
GROUP BY gzjwlh, sales_month, big_category
ORDER BY gzjwlh
```



​	4.2、物料号、捆绑料号、销售月份、在保月份：

​	1、sql_base_data:

```sql
SELECT
		btt.material_mode,
		btt.bundling_number, 
		btt.big_category,
		btt.stare_month,
		TO_CHAR(gs.warranty_month, 'YYYY-MM') AS warranty_month
FROM (
		SELECT DISTINCT
				material_mode,
				bundling_number,
				spare_parts_category AS big_category,
				TO_CHAR(server_stare_time, 'YYYY-MM') AS stare_month
		FROM bom_total_table
		WHERE material_mode IS NOT NULL
			AND EXTRACT(YEAR FROM server_stare_time) = EXTRACT(YEAR FROM CURRENT_DATE)
			AND spare_parts_category IN ('DDR4内存', 'DDR5内存')
) btt
CROSS JOIN LATERAL generate_series(
		to_date(btt.stare_month, 'YYYY-MM')::timestamp,
    date_trunc('month', CURRENT_DATE),
    interval '1 month'
) AS gs(warranty_month)
ORDER BY material_mode
```

4.3、销量、在保数量:

sql_bom_data：

```sql
SELECT
	material_mode,
	sum(sum_count) sum_num,
	TO_CHAR(server_stare_time, 'YYYY-MM') AS stare_month,
	TO_CHAR(server_end_time, 'YYYY-MM') AS end_month,
	spare_parts_category AS big_category
FROM bom_total_table
WHERE
	EXTRACT(YEAR FROM server_stare_time) = EXTRACT(YEAR FROM CURRENT_DATE)
	AND spare_parts_category IN ('DDR4内存', 'DDR5内存')
GROUP BY material_mode,stare_month,end_month,big_category
ORDER BY material_mode
```

​	1、sql_base_data作为基础数据

​	2、sql_bom_data查询销量

​	3、

​		销量：material_mode=material_mode and stare_month=stare_month and big_category=big_category，汇总sum_num。

​		在保数量：material_mode=material_mode and stare_month=stare_month and big_category=big_category and warranty_month<=end_month，汇总sum_num。

​	4、报修数量：

​		gzjwlh=material_mode and sales_month=stare_month and big_category=big_category，取repair_num

​		报修数量和在保月份没关系，不同在保月份的报修数量相同

5、以有“报修数量”的物料号为主，将 物料号、捆绑料号、销售月份、在保月份、销量、在保数量、报修数量存入中间表，当下拉框选择后，再查询出数据返回到页面

**刷新逻辑：**

1、基础数据sql：物料号、捆绑料号、备件大类、备件大类Ⅰ级、产品Ⅱ级分类、产品Ⅲ级分类、自然年月、报修数量

```sql
WITH comp_repair_num AS (
	SELECT
		gzjwlh,
		TO_CHAR(cpr.create_time, 'YYYY/MM') AS repair_month,
		count(*) AS repair_num
	FROM compute_product_report cpr
	LEFT JOIN base_material bm ON cpr.gzjwlh = bm.material_code
	WHERE TO_CHAR(cpr.create_time, 'YYYY') IN ('2024', '2025', '2026')
	GROUP BY gzjwlh, repair_month
),
comp_base AS (
	SELECT
			rd.gzjwlh AS material_mode,
			rd.bundling_number,
			rd.big_category,
			rd.big_category1,
			rd.pro2,
			rd.pro3,
			TO_CHAR(gs.natural_month, 'YYYY/MM') AS natural_month
	FROM (
			SELECT
					cpr.gzjwlh,
					max(bm.bundling_number) bundling_number,
					max(bm.spare_parts_category) AS big_category,
					max(bm.spare_parts_category_1) AS big_category1,
					max(bm.name) AS pro2,
					max(bm.product_category3) AS pro3
			FROM compute_product_report cpr
			LEFT JOIN base_material bm ON bm.material_code = cpr.gzjwlh
			WHERE cpr.gzjwlh IS NOT NULL
					AND TO_CHAR(cpr.create_time, 'YYYY') IN ('2024', '2025', '2026')
			GROUP BY cpr.gzjwlh
	) rd
	CROSS JOIN LATERAL generate_series(
			to_date('2024/01', 'YYYY/MM')::timestamp,
			date_trunc('month', CURRENT_DATE),
			interval '1 month'
	) AS gs(natural_month)
)
SELECT
	material_mode,
	bundling_number,
	big_category,
	big_category1,
	pro2, pro3,
	natural_month,
	COALESCE(repair_num, 0) repair_num
FROM comp_base cb
LEFT JOIN comp_repair_num crn ON cb.material_mode = crn.gzjwlh AND cb.natural_month = crn.repair_month
ORDER BY material_mode
```

sql中的2024、2025、2026、2024/01等涉及年月的部分替换成 "年份"下拉框中的年份范围。(此处如果不清楚可以向我提问。)



2、在保数量sql：物料号、自然年月、在保数量

```sql
WITH bom_num AS (
	SELECT 
		material_mode,
		TO_CHAR(server_stare_time, 'YYYY/MM') stare_month,
		TO_CHAR(server_end_time, 'YYYY/MM') end_month,
		sum_count
	FROM bom_total_table
	ORDER BY material_mode
),
bom_base AS (
	SELECT
		material_mode,
		TO_CHAR(gs.natural_month, 'YYYY/MM') AS natural_month
	FROM (
			SELECT DISTINCT material_mode
			FROM bom_total_table
	) rd
	CROSS JOIN LATERAL generate_series(
			to_date('2024/01', 'YYYY/MM')::timestamp,
			date_trunc('month', CURRENT_DATE),
			interval '1 month'
	) AS gs(natural_month)
)

SELECT
    a.material_mode,
    a.natural_month,
    COALESCE(SUM(b.sum_count), 0) AS total_sum_count   -- 无匹配时返回 0
FROM bom_base a
LEFT JOIN bom_num b
    ON a.material_mode = b.material_mode
    AND b.stare_month <= a.natural_month
    AND a.natural_month <= b.end_month
GROUP BY a.material_mode, a.natural_month
ORDER BY a.material_mode, a.natural_month
```

sql中的2024/01等涉及年月的部分替换成 "年份"下拉框中的年份范围。(此处如果不清楚可以向我提问。)

以'基础数据sql'为左表，左连接'在保数量sql'。连接条件为 物料号 and 自然年月



3、将结果写入中间表，使用sql语句批量插入，一批500条。需要增加create_date



**主表数据计算：**

1、按“维度”下拉框中选择的值，汇总'在保数量'、'报修数量'

2、故障率 = (在保数量/报修数量)*100 %，保留两位小数。

3、时间范围字段的值：取时间范围内故障率的平均值。例如：2025/02-2026/01 = sum(2025/02故障率+2025/03故障率+...+2025/12故障率+2026/01故障率)/12

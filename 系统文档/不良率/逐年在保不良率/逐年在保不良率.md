#### 逐年在保不良率

在不良率系统-’维修品质不良率报表‘菜单和’备件不良率‘菜单中间增加一个菜单’在保不良率‘。

##### 模型：

**逐年在保不良率：**

1、页面按钮等：

​	1.1、下拉框1：自然年、第几年。默认值为"自然年"

​	1.2、下拉框2：物料号、捆绑料号、备件大类、备件大类Ⅰ级、产品Ⅱ级分类、产品Ⅲ级分类。默认值是"物料号"

​	1.3、刷新按钮

​	1.4、导出按钮

2、字段：

​	2.1、下拉框1为"自然年"时：类别、销售年份、自然年份、销量、在保数量、报修数量、不良率

​	2.2、下拉框1为"第几年"时：类别、第几年、在保数量、报修数量、不良率

3、刷新按钮调用刷新方法，更新两个中间表。选择下拉框的值后，进行数据获取。此模型需要在页面上展示，不需要设置任何权限。

​	4.1、逐年在保不良率分子表：

```sql
-- 计算维修收发货表-分子
WITH base_data AS(
	SELECT
			cpr.wlh,
			cpr.sales_year,
			gs.repair_year,
			(gs.repair_year - cpr.sales_year + 1) AS years
	FROM (		
			SELECT DISTINCT
				gzjwlh as wlh,
				EXTRACT(YEAR FROM field_131ea__c)::int AS sales_year	-- "服务开始时间"的年份
			FROM compute_product_report
	) cpr
	CROSS JOIN LATERAL generate_series(
			cpr.sales_year,
			EXTRACT(YEAR FROM CURRENT_DATE)::int
	) AS gs(repair_year)
	ORDER BY
			cpr.wlh,
			cpr.sales_year,
			gs.repair_year
),
cpr_data AS(
	SELECT
		gzjwlh,
		EXTRACT(YEAR FROM field_131ea__c)::int AS sales_year,
   EXTRACT(YEAR FROM create_time)::int AS repair_year,
		count(*) AS repair_num
	FROM compute_product_report
	GROUP BY gzjwlh, sales_year, repair_year
)

SELECT
    bd.wlh material_code, bm.bundling_number,
		bm.spare_parts_category big_type, bm.spare_parts_category_1 big_type_1, 
		bm.name pro_2, bm.product_category3 pro_3,
    bd.sales_year,
		bd.repair_year,
    bd.years,
		COALESCE(cd.repair_num, 0) AS repair_num
FROM base_data bd
LEFT JOIN base_material bm ON bm.material_code = bd.wlh
LEFT JOIN cpr_data cd ON cd.gzjwlh = bd.wlh AND cd.sales_year = bd.sales_year AND cd.repair_year = bd.repair_year
```

​	执行sql将数据入库。



​	4.2、逐年在保不良率分母表：

​	1、sql_base_data:

```sql
SELECT
		btt.material_mode,
		btt.bundling_number, btt.big_type, btt.big_type_1, btt.pro_2, btt.pro_3,
		btt.sales_year, gs.repair_year,
		(gs.repair_year - btt.sales_year + 1) AS years
FROM (
		SELECT DISTINCT
			material_mode,
			bm.bundling_number, bm.spare_parts_category big_type, bm.spare_parts_category_1 big_type_1, 
			bm.name pro_2, bm.product_category3 pro_3,
			EXTRACT(YEAR FROM server_stare_time)::int AS sales_year	-- "服务开始时间"的年份
		FROM bom_total_table btt
		LEFT JOIN base_material bm ON bm.material_code = btt.material_mode
) btt
CROSS JOIN LATERAL generate_series(
		btt.sales_year,
		EXTRACT(YEAR FROM CURRENT_DATE)::int
) AS gs(repair_year)
ORDER BY
		btt.material_mode,
		btt.sales_year,
		gs.repair_year
```

2、sql_bom_data:

```sql
SELECT 
	material_mode, sum(sum_count) sales_num, 
	EXTRACT(YEAR FROM server_stare_time)::int AS stare_year,
	EXTRACT(YEAR FROM server_end_time)::int AS end_year
FROM bom_total_table
GROUP BY material_mode,stare_year,end_year
ORDER BY material_mode,stare_year,end_year
```

​	2.1、sql_base_data后作为基础数据，准备进行数据计算。

​	2.2、sql_bom_data查询结果按material_mode为键构建为{material_mode: [{},{},{}..]}

​	2.3、使用python代码在sql_base_data结果中增加销量、在保数量：

​		销量：material_mode=material_mode and sales_year=stare_year，汇总sales_num

​		在保数量：material_mode=material_mode and sales_year=stare_year and repair_year<=end_year，汇总sales_num。

- 理论剩余保期内第*年不良率：

  - 1、“剩余保修月数”的值/12，保留整数位后+1，得到的值是几就计算到第几年。例如：6/12+1 = 1，则计算"理论剩余保期内第1年不良率"；32/12+1 = 3，则计算第1、第2、第3年不良率。剩余年默认为0。

  - 2、计算当前日期和“服务开始时间”的时间差，取整年。用结果分别加上步骤1中的几个年份，结果就是需要取值的年份。

- 理论剩余保期内第*年需求数：

  - 1、“剩余保修月数”的值/12，整数部分有几就算几年需求量，余数部分用来计算整数+1年的需求量。

  - 2、整数部分的 第几年需求量 = 总数量 * 理论剩余保期内第几年不良率 * 1，余数部分需求量 = 总数量 * 第几年不良率 * 余数
    例如：“剩余保修月数” = 33，33 / 12 = 2.75。则需要计算第1、第2年的完整需求量、第3年的部分需求量。第1年需求量 = 总数量 * 第1年不良率 * 1、第2年需求量 = 总数量 * 第2年不良率 * 1、第3年需求量 = 总数量 * 第3年不良率 * (2.75-2)

  - 注意：第*年不良率的值有可能带有%，例如0.35%或0.0035

2、获取结果表full_warranty_spare_parts

```sql
WITH bundling_stock_num AS(
	SELECT spare_parts_category category, bundling_number, sum(num) num
	FROM reservoir_area_stock
	GROUP BY spare_parts_category, bundling_number
),
warranty_process AS (
	SELECT
		spare_parts_category, bundling_number, max(material_desc) material_desc, sum(sum_count) sum_count,
		sum(theoretical_num_sum) theoretical_num_sum, sum(real_num_sum) real_num_sum
	FROM full_warranty_process
	GROUP BY spare_parts_category,bundling_number
)

SELECT
	wp.spare_parts_category, wp.bundling_number, material_desc, sum_count, bsn.num,
	theoretical_num_sum, (bsn.num - wp.theoretical_num_sum) AS diff_theoretical,
	real_num_sum, (bsn.num - wp.real_num_sum) AS diff_real
FROM warranty_process wp
LEFT JOIN bundling_stock_num bsn ON wp.spare_parts_category = bsn.category AND wp.bundling_number = bsn.bundling_number
```

#### BOM总表 优化

在现有的server_stare_time、server_end_time取值逻辑后，如果结果还是空时：

1、默认server_stare_time = write_time
2、提取出server_desc中的年份：

- ​	如果'年'字前是数字，就取出这个数字，如果有多个符合结果，取第一个。

  ​	例如：server_desc = '2U3年标准+，基础硬件安装'，提取出3年；

  ​	server_desc = '鲲泰维保服务:台式机-上门维保（5*9*NBD)-5年'，提取出5年。

  ​	server_desc = 'HDD-介质保留-3年，鲲泰维保服务:台式机-上门维保（5*9*NBD)-4年'，提取出3年

- 如果提取不到，默认为3年

3、server_end_time = server_stare_time + 提取出的年份

在“备件看板”下增加“行业&时效看板”页面

“行业&时效看板”页面描述：

​	1、最上面是一个数据表，可根据年份选择框来查询并展示数据，年份默认为当前年。

​		数据表字段：行业、服务时效、在保量、在保量合计、行业占比。

​	2、根据数据表的数据，绘制”行业“占比饼状图。这个饼状图的名字叫”FY26行业占比分类“，其中26年表示年份为26年，根据1中选择的年份动态改变。

​	3、根据数据表的数据，和下拉框的值来绘制”服务时效“占比饼状图。下拉框的内容固定为：政府、运营商、金融、国防、区域；默认值为政府。饼状图的名字固定叫”时效占比“。

​	4、根据数据表的数据，绘制柱状图，名字固定为”不同时效的行业分布图“。柱状图的横轴按时效分为四组："7*24*2H"、"7*24*4H"、"7*24*ND"、"基础保修"。每一组又有五个：政府、运营商、金融、国防、区域。



数据表取值逻辑：

```sql
SELECT industry_area, server_aging, sum(sum_count) sum_count
FROM(
	SELECT 
		CASE
			WHEN industry_area in ('政府', '安平', '互联网', '教育') THEN '政府'
			WHEN industry_area = '运营商' THEN '运营商'
			WHEN industry_area = '金融' THEN '金融'
			WHEN industry_area = '国防' THEN '国防'
			ELSE '区域'
		END industry_area, 
		server_aging, sum_count, server_stare_time, server_end_time
	FROM bom_total_table
	WHERE information_sources != '过保' 
			AND spare_parts_category = '主板'
			AND EXTRACT(YEAR FROM server_stare_time)::int = 2026
)btt
GROUP BY industry_area, server_aging
ORDER BY industry_area, server_aging DESC
```

在 spare_parts_menu.xml 文件的"数据审视"菜单中新增一个子菜单"过保召回清单"，该菜单应放置在"欠料调拨总表"和"版本管控&定制化"两个菜单项之间。

具体要求如下：

**菜单配置**：
- 菜单项名称：过保召回清单
- 父级菜单：data_review_menu（数据审视）
- 序列顺序：位于 material_shortage_menu 和 version_ctrl_customization_menu 之间

**页面字段显示**：
需要展示以下字段列：库房(city)、捆绑料号(bundling_number)、料号(sap_no)、数量(num)、描述(material_desc)、PN(supplier_pn)

**页面功能组件**：
- 包含导出按钮，用于导出当前数据显示
- 包含刷新按钮，用于更新数据

**数据刷新机制**：
点击刷新按钮时执行以下逻辑：
1. 删除现有缓存或临时数据
2. 执行指定的SQL查询获取最新数据：
```sql
WITH res_stock AS (
	SELECT ras.sap_no, ras.bundling_number, ras.city, sum(ras.num) num, max(ras.material_desc) material_desc, max(bm.supplier_pn) supplier_pn
	FROM reservoir_area_stock ras
	LEFT JOIN base_material bm ON ras.sap_no = bm.material_code
	WHERE num > 0
	GROUP BY ras.sap_no, ras.bundling_number, ras.city
),
sum_table_data AS (
	SELECT DISTINCT material_code, bundling_number, stock_location, information_sources
	FROM summary_kanban
	WHERE information_sources = '过保'
)
SELECT city, rs.bundling_number, sap_no, num, material_desc, supplier_pn
FROM res_stock rs
	LEFT JOIN sum_table_data std ON rs.sap_no = std.material_code AND rs.bundling_number = std.bundling_number AND rs.city = stock_location
WHERE information_sources = '过保'
```
3. 将查询结果存储到对应的数据显示表中以供前端展示

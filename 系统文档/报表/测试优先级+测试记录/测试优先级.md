在"备件测试数据管理"菜单下增加"测试优先级"

一、字段：物料代码、捆绑料号、物料描述、备件大类、测试级别、数量、SN、备件接收时间、备件停留时间、测试件类别、武汉总库库存、测试员。

"测试级别"：Selection类型，0: 高, 1: 中。"测试员"默认为空。

"测试件类别"、"测试员" 可编辑，其他字段设置为只读。

三、刷新逻辑：

1、先从WMS系统抓取"物料代码"、"数量"、"SN"、"备件接收时间"、"测试件类别"：

1.1、获取k3_im数据库权限，并执行sql

```
self.env['wms.abutment']._get_db_connection('k3_im')
```

```sql
-- k3_im库，物料库存页面
SELECT 
	NULL AS check_no,
	ext_material_id AS material_code, 
	aqty AS num,
	NULL AS sn,
	NULL AS received_time,
	'转储件' AS test_type
FROM om_storage
WHERE stock_id = 'KCDBJ-WHCSC' 
AND (aqty != 0 OR iqty != 0 OR oqty != 0)
```

1.2、获取k3_repair数据库权限，并执行sql

```
self.env['wms.abutment']._get_db_connection('k3_repair')
```

```sql
-- k3_repair 测试单页面
SELECT 
	oc.check_no,
	oci.out_material_code AS material_code, 
	oci.qty AS num,
	oci.sn,
	oc.create_time AS received_time,
	CASE source_type
		WHEN '1' THEN '故障件'	-- 来源 = 换件单
		WHEN '2' THEN '修复件'	-- 来源 = 返厂单
		ELSE ''
	END test_type
FROM od_check oc
LEFT JOIN od_check_item oci ON oci.check_no = oc.check_no
WHERE oc.check_status IN ('10','20')	-- 单据状态 in 待测试、测试中
ORDER BY oc.check_no
```

1.3、合并查询的数据，并将material_code的格式化：去除前面的0，在后6位前插入"-"。例如：000000000302002053格式化为302-002053



2、继续拼接其他字段：

2.1、按物料代码从base_material表中匹配 捆绑料号、物料描述、备件大类：

```sql
SELECT material_code, max(bundling_number) bundling_number, max(material_desc) material_desc,
max(spare_parts_category) spare_parts_category, max(test_priority) test_priority
FROM base_material
GROUP BY material_code
```

2.2、按捆绑料号 从reservoir_area_stock 匹配 武汉总库库存

```sql
SELECT bundling_number, sum(num) num
FROM reservoir_area_stock
WHERE city = '武汉'
GROUP BY bundling_number
```

2.3、备件停留时间 = 当天时间-备件接收时间。

​	当"备件停留时间" <= 7时，"备件停留时间"文字设置为绿色；

​	当7 < "备件停留时间" <= 14时，"备件停留时间"文字设置为黄色；

​	当"备件停留时间" > 14时，"备件停留时间"文字设置为红色；

2.4、测试级别：

​	按物料代码 从base_material表匹配test_priority，测试级别 = test_priority；

​	if "武汉总库库存" = 0，测试级别 = 高；

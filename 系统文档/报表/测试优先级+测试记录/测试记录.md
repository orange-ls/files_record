##### 测试记录数据概览

1、在"备件测试数据管理"菜单下增加"测试记录"

2、字段：姓名、合计、通过件、未通过件、固件定制/升级件、返修百分比(%)

3、逻辑：

​	3.1、姓名、合计、通过件、未通过件、固件定制/升级件：

	SELECT 
	tester,
	count(*) sum_num,
	sum(
		CASE conclusion
			WHEN 'OK' THEN 1
			WHEN '超时' THEN 1
			ELSE 0
		END
	) pass_num,
	sum(
		CASE conclusion
			WHEN '不良品' THEN 1
			ELSE 0
		END
	) not_pass_num,
	sum(
		CASE rma_no
			WHEN '转储件' THEN 1
			ELSE 0
		END
	) not_pass_num
	FROM test_record
	GROUP BY tester
​	3.2、返修百分比(%) = 未通过件/(合计-固件定制/升级件)*100%，保留两位小数

​	3.3、最后增加一行汇总，返修百分比(%) = 汇总后的数据计算



4、页面上增加开始时间、结束时间、查询、导出 四个按钮。

​	4.1、选择时间范围查询后，步骤3.1中的sql增加where语句，按test_start_time字段筛选

​	4.2、开始时间默认为当前月第一天；结束时间默认为当前日期

​	4.3、第一次进入该表，按默认时间范围查询。手动设置好时间范围并点击查询按钮后，再按设置的时间范围查询

#### 重点项目监控需求

一、增加模块：在xc_addons/xc_report中添加：重点项目监控。放在“质量管理部”菜单最后面。

二、字段：数据来源举例、项目名称、时间、立项编号、存量、来源、问题类别、涉及物料、行业负责人、一线负责人、二线负责人、预警灯机制、跟进进度、闭环时间、结论、备注。

​	预警灯机制：0：红灯，当前有事件在处理中。1：黄灯，事件挂起或者暂时解决。2：绿灯：已核实确认非批次问题。特殊物料项目(手动导入)的数据默认设置为绿灯。

三、数据来源分为四个部分：报表系统-年度回溯跟踪记录、报表系统-重点问题跟进清单、不良率系统-维修品质不良率报表、特殊物料项目(手动导入)。

四、具体逻辑：

1、系统刷新部分：

​	1.1、报表系统-年度回溯跟踪记录：

```sql
SELECT 
	'BCM-年度回溯跟踪记录' AS examples_data_sources,
	'' AS proj_name,
	CONCAT(year, month) AS time,
	'' AS crm_no,
	'现网问题' AS sources,
	'客户投诉' AS question_category,
	'' AS material_code,
	'' AS closed_time
FROM "customer_complaint_tracking_record"
```

​	1.2、报表系统-重点问题跟进清单：

```sql
SELECT 
	'BCM-重点问题跟进清单' AS examples_data_sources,
	'' AS proj_name,
	creation_date AS time,
	'' AS crm_no,
	'现网问题' AS sources,
	'重大问题' AS question_category,
	'' AS material_code,
	closure_date AS closed_time
FROM "network_hard_problem"
```

​	1.3、不良率系统-维修品质不良率报表

```sql
SELECT 
	'NA客户故障率异常部分' AS examples_data_sources,
	proj_name_sn AS proj_name,
	CONCAT(xsnf, '年') AS time,
	crm_no_sn AS crm_no,
	'NA客户' AS sources,
	'故障率异常' AS question_category,
	wldm AS material_code,
	'' AS closed_time
FROM "supply_defect_rate"
WHERE flag = '1' AND xsnf != '汇总' 
	AND CAST(replace(hardware_rate, '%', '') AS numeric) > CAST(replace(gysllbll, '%', '') AS numeric)
ORDER BY proj_name,time,crm_no
```

​	1.4、将前面3个部分抓取的数据合并后，其他字段的逻辑如下：

存量：

```sql
-- 按CRM立项编号 获取存量
SELECT crm_no, count(*) num
FROM sn_service_complete_info
WHERE crm_no is not NULL AND crm_no != ''
GROUP BY crm_no
```

行业负责人：

```sql
-- 按CRM立项编号 获取行业负责人
SELECT DISTINCT 
	crm_no, proj_industry,
	CASE proj_industry
		WHEN '金融' THEN '刘慧'
		WHEN '运营商' THEN '胡红月'
		WHEN '国防' THEN '吴立宁'
		WHEN '政府' THEN '杨佳'
	ELSE ''
END industry_leader
FROM sn_service_complete_info
WHERE crm_no is not NULL AND crm_no != '' AND proj_industry in ('金融','运营商','国防','政府')
```

一线责任人：

```sql
-- 按CRM立项编号 获取一线责任人
SELECT crm_no, max(sales) sales
FROM sn_service_complete_info
WHERE crm_no is not NULL AND crm_no != '' AND sales is not NULL
GROUP BY crm_no
```

其他字段默认为空，用户可以在页面上编辑。



2、特殊物料项目(手动导入)：

使用excel导入。自动把excel的表头与字段定义的中文表头对应赋值。

数据来源举例：默认为“特殊物料-手动上传”。

预警灯机制：默认设置为绿灯。



注意：

1、预警灯机制默认为空，只有手动导入的数据才默认为绿灯。

2、刷新数据时，使用增量刷新，不要删除旧数据。唯一键是：数据来源举例、项目名称、时间、立项编号。

3、删除只能勾选以后点删除按钮删除。

4、存量、行业负责人、一线责任人 不要都写在查询基础数据的sql中了，将基础数据查出来后，使用python代码赋值每一条数据

5、预警灯机制：当选择不同内容时，根据文字的内容变换单元格中文字的背景色。例如：选红色时，文字的背景色变成红色。选黄色时，文字的背景色变成黄色。选绿色时，文字的背景色变成绿色。
